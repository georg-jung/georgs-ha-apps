# Georg's Home Assistant Apps

Georg Jung's personal Home Assistant app (add-on) repository. Add it in Home
Assistant under **Settings → Apps → App store → ⋮ → Repositories** as
`https://github.com/georg-jung/georgs-ha-apps`. The images are private; each
app's documentation says which registry credential Home Assistant needs before
it can install.

| App | Description |
| --- | --- |
| [Music Capsule Sidecar](music-capsule-sidecar/DOCS.md) | Runs Music Capsule's import sidecar on your home network |
